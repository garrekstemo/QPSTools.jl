Cavity Spectroscopy

The lab-side cavity layer: a JASCO-backed CavitySpectrum, load_cavity, and a metadata-aware fit_cavity_spectrum dispatch. See src/cavity.jl.

The physics and fitting (fit_dispersion, cavity_mode_energy, polariton_branches, polariton_eigenvalues, hopfield_coefficients, compute_cavity_transmittance, cavity_transmittance, refractive_index, extinction_coeff, and the CavityFitResult / DispersionFitResult types) live in CavitySpectroscopy.jl and are re-exported here. See the CavitySpectroscopy.jl documentation for those.

Types

QPSTools.CavitySpectrum — Type
CavitySpectrum <: AnnotatedSpectrum

Cavity FTIR transmission spectrum with sample metadata.

Fields

  • data::JASCOSpectrum - Raw spectrum from JASCOFiles.jl
  • sample::Dict{String,Any} - Sample metadata (mirror, cavity_length, angle, etc.)
  • path::String - File path

Accessing data

  • Wavenumber: spec.data.x
  • Transmittance: spec.data.y
  • Sample info: spec.sample["mirror"], spec.sample["angle"]

Fitting

CavitySpectroscopy.fit_cavity_spectrum — Function
fit_cavity_spectrum(spec::CavitySpectrum; kwargs...)

Fit a JASCO-backed CavitySpectrum. Extracts wavenumber/transmittance, auto-normalizes percent transmittance (0–100) to fractional, and pulls the cavity length from sample metadata ("cavity_length") when L is not given. Numerics from CavitySpectroscopy.
